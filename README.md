# Кинематика по четырём PDF — новый фильм

**24 минуты 6 секунд, 1920×1080, 60 кадров/с.** Фон — чистый чёрный,
звуковой дорожки нет. Текст для самостоятельной озвучки содержит 100 фрагментов
с таймкодами. Фильм охватывает 37 страниц четырёх предоставленных конспектов:
кинематику, графики, относительное и вращательное движение, баллистику.

- [Скачать новый фильм MP4](https://github.com/kolyAA1123/1/raw/refs/heads/main/kinematika_po_pdf_1080p60.mp4)
- [Скачать текст для озвучки TXT](https://github.com/kolyAA1123/1/raw/refs/heads/main/kinematika_po_pdf_ozvuchka.txt)
- [Читать текст для озвучки](kinematika_po_pdf_ozvuchka.txt)
- [Скачать исходники, раскадровку и сверку с PDF ZIP](https://github.com/kolyAA1123/1/raw/refs/heads/main/kinematika_po_pdf_sources.zip)

Если файл открылся в браузере, нажмите значок скачивания или выберите
«Сохранить видео как…» правой кнопкой мыши. На странице файла в GitHub используйте
**Download raw file** (стрелка вниз). Загруженный MP4 откройте двойным щелчком.
Устанавливать Codex для просмотра не нужно.

Графики строятся постепенно; движения доходят до конечного состояния. Результаты
остаются на экране перед плавным исчезновением. Численные примеры взяты из PDF,
а исправления очевидных опечаток описаны в `SOURCE_NOTES.md` внутри архива.
Оригинальные PDF в архив не включены.

Для повторного рендера распакуйте архив, активируйте `setup_env.sh` и выполните
из каталога `pdf_lesson` команду `python render_pdf.py --jobs 3`.
Подробная инструкция и таблица всех 20 глав находятся в `pdf_lesson/README.md`
внутри архива.

## Повторный рендер в подготовленной облачной среде

Исходники и инструкции доступны в `kinematika_sources.zip`; в текущей облачной
среде они уже находятся в `/workspace/1`. Из этого каталога:

```bash
source setup_env.sh
python render_all.py --jobs 3
```

Команда создаёт `output/kinematika_1080p60.mp4` без аудио. Загрузка голосовой модели,
генерация речи и работающий речевой сервис не нужны. `narration.md` и
`tekst_ozvuchki.txt` содержат текст, `storyboard.md` — подробную раскадровку.

При необходимости восстановить зависимости на этой машине Debian:

```bash
bash install.sh
source setup_env.sh
```

Для черновой проверки: `python render_all.py --preview --jobs 3`.
Для одной сцены: `python -m manim kinematics.py Projectile -r 1920,1080 --fps 60`.

Для следующих роликов приняты те же настройки: чёрный фон, видео без ИИ-голоса,
отдельный русский текст для самостоятельной озвучки. Содержание определяется
присланными файлами и заданием пользователя.
